## 2024-07-10 - Actionable Empty States
**Learning:** Empty states present an opportunity to guide users when data is missing. Replacing static text with an actionable CTA (like a 'Clear search' button when no results match a query) transforms a dead end into a helpful interaction.
**Action:** When designing or refactoring empty states, always consider if the user can take an immediate action (e.g., clearing filters, adding an item, checking settings) and provide a button to facilitate it directly.
