## 2024-05-17 - Add Active Visual States for Selection Modes

**Learning:** When users select an item in a list or grid, changing a small checkbox is often insufficient for providing clear feedback, especially for larger hit areas like book cards. Users need immediate, obvious visual feedback that an item's state has changed.
**Action:** Always add an active visual state (e.g., background tint, border highlight, or ring) to the primary container when an item is selected in a multi-select or list view to ensure the selection is obvious at a glance without relying solely on a small indicator.
