## 2025-02-18 - Applying cursor-not-allowed to Button Wrapper Spans
**Learning:** Applying Tailwind's `disabled:cursor-not-allowed` to disabled `<button>` elements generally fails when `disabled:pointer-events-none` is also applied. Disabling pointer events intrinsically drops mouse interactions including hover states, effectively ignoring `cursor-not-allowed` styles. This frequently leads to inaccessible disabled UI states because the user doesn't get visual cursor feedback or tooltips.
**Action:** When creating disabled buttons with tooltips or cursors, preserve `disabled:pointer-events-none` on the button itself (so clicks don't fire and the interaction state represents disabled), but apply `cursor-not-allowed` and the tooltip `title` to a parent wrapper element (e.g. `<span className={cx('flex', isDisabled && 'cursor-not-allowed')} title={...}>`).
