## 2024-07-07 - Add disabled cursor to pointer-events-none elements
**Learning:** In Tailwind CSS, applying `pointer-events-none` to a disabled button prevents it from receiving mouse events, which intrinsically breaks `cursor-not-allowed` hover states. However, removing `pointer-events-none` from the button can break wrapper elements (like tooltips) that need to catch mouse events bubbling up or interacting with the disabled element.
**Action:** To safely display a disabled cursor with a tooltip, keep `pointer-events-none` on the disabled button itself and apply `cursor-not-allowed` conditionally to its wrapper element (e.g. `<span className={cx('flex', isDisabled && 'cursor-not-allowed')} title="...">`). This preserves the tooltip and visual state while still providing the proper disabled cursor UX.
