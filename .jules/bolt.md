## 2025-05-19 - Use CSS Descendant Selectors to Prevent O(N) Re-renders
**Learning:** When building virtualized lists or grids (like in `VirtualizedLibraryBooks`), passing a dynamic prop (like `selectionModeActive`) to every child component to toggle UI visibility (like checkbox opacity) causes the entire list to re-render whenever the value changes. This turns an O(1) state change into an O(N) re-render bottleneck.
**Action:** Instead of managing visibility via React props, manage it via CSS. Apply a state class (e.g., `selection-mode-active`) to the parent container, and use Tailwind's descendant selectors (`[.selection-mode-active_&]:opacity-100`) on the children. This offloads the visibility toggling to the browser's style engine, preserving component memoization and making updates instant (O(1)).
