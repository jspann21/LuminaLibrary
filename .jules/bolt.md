## 2024-05-17 - Bulk UI toggles in virtualized lists
**Learning:** In virtualized lists (like `VirtualizedLibraryBooks`), passing a global boolean state prop (e.g., `selectionModeActive`) to every child component to toggle UI visibility (like checkboxes) causes an O(N) React re-render of all currently mounted items whenever that global state changes. This defeats the purpose of React.memo on the child components.
**Action:** Instead of passing the boolean state to children, apply a class (e.g., `selection-mode`) to the parent container when the state is active. Then, in the child component's styling, use Tailwind CSS descendant selectors (e.g., `[.selection-mode_&]:opacity-100`) to toggle the visibility purely via CSS. This prevents React from needing to re-render the child components at all.
