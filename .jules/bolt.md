## 2026-04-16 - Bolt Optimization: Deferred Join Pagination & Correlated Subqueries\n**Learning:** In SQLite, when aggregating metrics like file counts using `LEFT JOIN` combined with `GROUP BY` on large base tables, the query forces an expensive full-table scan and intermediate grouping. This is particularly problematic for functions computing duplicate books across the entire library (like `find_book_by_title_author_conn` and `consolidate_duplicate_books`).\n**Action:** Replaced the `LEFT JOIN` + `GROUP BY` combinations with correlated scalar subqueries (e.g., `(SELECT COUNT(DISTINCT bf.file_id) FROM book_files bf WHERE bf.book_id = b.id)`) directly in the `SELECT` clause. This avoids building massive intermediate result sets in memory and utilizes fast index lookups instead, significantly improving query execution time for whole-library operations.
