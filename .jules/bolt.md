## 2025-02-12 - Use CSS descendant selectors for bulk UI visibility toggles in virtualized lists
**Learning:** When dealing with virtualized lists or large collections of React components, passing a global application state (like `selectionModeActive`) as a prop to every child component forces an O(N) re-render across the entire visible collection every time that global state toggles. This defeats the purpose of component memoization (`React.memo`) for the components whose individual state hasn't changed.
**Action:** For simple UI visibility changes (like showing selection checkboxes on all items when at least one is selected), apply a CSS class (e.g., `selection-mode-active`) to the parent/wrapper container instead. Then, use CSS descendant selectors (e.g., `[.selection-mode-active_&]:opacity-100` in Tailwind) inside the child components. This allows `React.memo` to bail out of rendering unselected items (since their props remain identical), offloading the visibility toggle entirely to the browser's CSS engine.
