## 2024-06-25 - Contextual Keyboard Shortcut Hints
**Learning:** Users often don't know keyboard shortcuts exist unless they are surfaced in the UI. A small visual hint inside the search input (like `Ctrl` `F`) improves discoverability without cluttering the interface. Hiding it on focus/typing ensures it doesn't distract.
**Action:** Add similar subtle shortcut hints to other frequently used inputs or buttons in the future to improve keyboard navigation accessibility and efficiency.
