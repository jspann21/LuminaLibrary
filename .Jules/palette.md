## 2024-05-18 - Search Shortcut Hint
**Learning:** Exposing hidden keyboard shortcuts (like Ctrl+F for search) directly within empty input fields using visual hints (like `<kbd>` tags) improves discoverability and makes power-user features accessible to everyone.
**Action:** Use absolutely positioned, semi-transparent elements inside inputs that fade out when the input has content to guide users without cluttering the UI.
