## 2024-06-12 - Add search shortcut hint
**Learning:** Adding a subtle keyboard shortcut hint (`Ctrl F`) inside empty search inputs improves feature discoverability without cluttering the interface. Using small `<kbd>` tags with a muted style works well as an invisible UX enhancement.
**Action:** When adding global keyboard shortcuts, ensure they are visible contextually in the UI (e.g. inside the input they focus, or in tooltips) to help users learn them naturally.
