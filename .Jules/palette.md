## 2024-05-24 - Add accessible labels to manual book entry form
**Learning:** Adding `htmlFor` and `id` tags significantly improves keyboard navigability and accessibility for screen readers on forms. Highlighting required fields with an asterisk reduces user confusion.
**Action:** Always link form `<label>` and `<input>` together with `htmlFor` and `id`. Consistently mark required fields visually if validation enforces them.
