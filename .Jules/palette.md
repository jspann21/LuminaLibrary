## 2025-02-18 - Visual Shortcut Hints
**Learning:** Displaying Windows-specific keyboard conventions (like "Ctrl") is appropriate for Lumina Library since it's a dedicated Windows desktop application. Adding these hints next to inputs makes powerful existing keyboard navigation more discoverable without cluttering the interface.
**Action:** When adding shortcut hints to input fields, ensure adequate padding is added to the input (e.g., `pr-16`) so user text doesn't overlap with the absolute-positioned hint.
