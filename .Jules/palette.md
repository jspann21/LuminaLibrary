## 2024-06-13 - Add Keyboard Shortcut Hint
**Learning:** Users didn't realize they could use Ctrl+F to focus the search bar. Exposing keyboard shortcuts as visible `<kbd>` hints inside input fields improves discoverability of existing power-user features.
**Action:** Added a `Ctrl F` hint inside the search bar, which hides when typing starts (replaced by the clear button) or when focused.
