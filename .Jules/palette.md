## 2024-06-02 - Search Keyboard Shortcut Discoverability
**Learning:** Adding a subtle, contextual keyboard hint (`<kbd>`) directly inside empty search inputs significantly improves feature discoverability without cluttering the interface.
**Action:** Always consider embedding platform-aware keyboard shortcuts (e.g., displaying ⌘F on Mac vs Ctrl+F on Windows) as hints within placeholder areas for frequently used actions like search or command palettes.
